# allen_20251SEN101_saccoLoanTracker
SACCO loan tracking system - members, loans, repayments, arrears and penalties
## Phase I – Business Process Modeling

**Business Process:** Loan Application Process for SACCO

This process shows how a member applies for a loan, how SACCO staff verify eligibility and documents, how the system records the application, and how the final decision (Approved / Rejected) is made. It helps SACCO management make fair and clear loan decisions and keep a proper record of all applications.
